# math-in-code

implementing stuff from my math classes so i actually understand it. every file runs on its own and prints checks against the textbook answer.

- `graph_theory.py` - degree sequences (havel-hakimi), bipartite check, coloring, prufer codes, cayley's formula by brute force, euler paths (math 154)
- `probability_sims.py` - birthday problem, monty hall, coupon collector, derangements, clt, all exact vs simulated (math 180a)
- `statistics_inference.py` - biased vs unbiased variance, mles, t intervals with a coverage simulation, wilson interval, comparing estimators by mse (math 181a)
- `linear_algebra.py` - rref with exact fractions, rank, inverse, null space, gram-schmidt, power iteration (math 18)
- `number_theory_proofs.py` - checking induction/divisibility claims before proving them, bezout, fermat, pigeonhole (math 109)
